# SceneTalk
英会話アプリ

## 1. サービス概要（※最後に書いてOK）

接客シーンに特化したAI英会話練習アプリです。
飲食店で働くスタッフが、外国人のお客様への対応を練習できます。


## 2. このアイデアはどこから生まれたか

### 2-1. きっかけとなった体験・感情
学生時代に、鉄板焼き・お好み焼き屋でアルバイトをしていた時のことです。

外国人のお客様が来店され、注文を取りに行った際、
「このメニューはどういった食べ物なのか」といった
質問に英語で説明することができませんでした。

お客様は困った表情をされ、私も何も説明できず、
申し訳ない気持ちと、もどかしい気持ちでいっぱいになりました。

### 2-2. なぜそれが「気になった」のか

せっかく数あるお店の中から当店を選んで来店してくれたのに、
お客様の「何が食べたいか」という気持ちを汲み取れず、
満足のいく接客ができなかったことが心残りでした。

また、注文を取る際に時間がかかってしまい、
他のお客様や一緒に働く従業員にも迷惑をかけてしまったことも
気になっていました。

「もっとスムーズに対応できていれば、お客様も従業員も
みんなが気持ちよく過ごせたのに」という思いが、
今でも忘れられません。

## 3. 課題の整理（表面的になっていないか）

### 3-1. 表に見えている困りごと
外国人のお客様が来店した際、英語で何を言っているのか理解できず、
こちらも何と言えばいいのかわからない。
その結果、注文を正確に取ることができず、お客様の要望に応えられない。
### 3-2. 本当に解決したい課題は何か

相手の要望に応えることができないから。
お客様に満足してもらえず、お店がスムーズに回らないから。
お客様が不快な思いをして帰ってしまい、自分も申し訳ない気持ちになるから。
外国人のお客様が来るたびに不安になり、接客に自信が持てなくなるから。


→ 本当に解決したい課題：言語の壁により、外国人のお客様に満足のいくサービスを提供できず、
接客に自信が持てなくなること。
また、対応に時間がかかることで周囲に迷惑をかけていると感じ、
自己肯定感が下がってしまうこと。


## 4. 想定ユーザーについて

### 4-1. 想定しているユーザー
年齢設定:
  - 年齢:16～22歳(高校生～大学生)
  - 理由:
    この年代は、飲食店でアルバイトを始める機会が多く、
    接客経験が浅いため、外国人対応に不安を感じやすい。
    
    また、スマートフォンの操作に慣れており、
    アプリを使った学習に抵抗が少ないため、
    このサービスを日常的に活用してもらいやすい。

生活・状況設定:
  - 生活・状況:外国人観光客が多い店舗で働く、英語初心者のアルバイトスタッフ
  - 理由:
    外国人のお客様が来店するたびに、
    「何を言っているかわからない」「どう答えればいいかわからない」
    という不安を感じている。
    
    このアプリを使えば、よく使う接客フレーズを事前に学習でき、
    実際の接客場面でもすぐに使える表現を確認できるため、
    自信を持って対応できるようになる。

環境設定:
  - 環境:外国人観光客が多く訪れる飲食店(観光地、繁華街など)
  - 理由:
   このような店舗では、英語対応が頻繁に発生するため、
    スタッフは常に「次に外国人が来たらどうしよう」という
    プレッシャーを抱えている。
    
    このアプリでは、店舗のメニューや接客シーンに特化した
    フレーズを学習できるため、実際の業務にすぐ活かせる。
    
    また、帰宅後の空き時間に、
    一人でAIと会話練習ができるため、
    忙しいアルバイトスタッフでも無理なく続けられる。
    音声を使うため、静かな場所や一人になれる環境が必要だが、
    帰宅後の自室や、通勤前の自宅など、
    アルバイトスタッフが日常的に確保できる場所で学習できる。
    
    また、音声入力が難しい環境では、
    テキストでフレーズを確認する「復習モード」も用意されているため、
    休憩時間にスマホで軽く確認することもできる。

## 7. このアプリで実現すること

### MVPで作る機能
#### 1. ユーザー登録・ログイン機能
- ユーザーが新規登録し、ログインできる

#### 2. 接客フレーズの一覧表示機能
- 飲食店の接客シーン別(注文・メニュー説明・会計など)に、

#### 3. AI講師との会話練習機能
- 選んだシチュエーションに応じて、AI講師と音声で会話練習ができる

- AIがユーザーの発音を評価し、改善点をフィードバックする

#### 2. 復習モード
- 音声を使えない環境でも、テキストでフレーズを確認できる

#### 3. カスタムフレーズ登録機能
- 自分の店舗でよく使うフレーズを、ユーザー自身が登録できる
## 8. このアプリの懸念点とその対策
※最低1つは必ず書いてください。

このアプリが**うまくいかない可能性**と、
それに対して**どう向き合おうとしているか**を書いてください。

### 懸念点①

- 何が問題になりそうか：  音声練習をする環境を確保できないユーザーがいる

- なぜそう思うか：飲食店のアルバイトスタッフは、家族と住んでいたり、自宅で声を出して練習すると周りに迷惑をかけたり、  恥ずかしさを感じたりする可能性がある。
- そのために考えている対策：音声練習ができない環境でも学習を続けられるように、「復習モード」を用意する。
　復習モードでは、音声を使わずに、
  テキストでフレーズを確認したり、
  AIとチャット形式で会話練習ができるようにする。
  
  これにより、音声を使える環境では音声で練習し、
  使えない環境ではテキストで学習するという、
  柔軟な学習スタイルを実現する。

## 9. 今後の展開・発展の方向性

このアプリは、
**「投稿して終わり」にならないために**
どんな広がりが考えられますか？

### 観点（すべて答えなくてOK）

- ユーザーはなぜ使い続ける？
→  → 実際の接客で使えるフレーズを学べて、
     学習した内容がすぐに仕事で役立つからさらに、実際の接客で「このフレーズは通じた!」という成功体験を積み重ねられる。
- 続けることで何が変わる？
 → 最初は不安だった外国人のお客様への接客が、
     「今日学んだフレーズを使ってみよう」という
     前向きな気持ちで対応できるようになる。
     
     また、フレーズを覚えることで、
     スマホの翻訳アプリに頼らず、
     自分の言葉で接客できるようになる。


### 今考えている発展案

- 機能追加の方向性： 
#### 1. 好感度機能の追加
  AI講師との会話練習を続けることで、
  AI講師との「好感度」が上がっていく仕組み。
  
  好感度が上がると、AI講師の反応が変わったり、
  新しいフレーズが解放されたりすることで、
  ゲーム感覚で学習を続けられるようにする。
#### 2. おすすめフレーズ提案機能
  学習履歴をもとに、AIが
  「次はこのフレーズを練習しましょう」と
  個別におすすめを提案する機能。
  
  これにより、ユーザーは
  「次に何を学べばいいか」を迷わずに
  学習を続けられる。
- UI・体験の改善：
  #### 1. 短時間で学習できる設計
  1つのフレーズ練習を3〜5分で終えられるようにし、
  休憩時間などのスキマ時間で学習できるようにする。
  
  #### 2. 音声練習の環境に配慮
  音声を使えない環境でも学習を続けられるように、
  テキストでフレーズを確認したり、
  チャット形式で会話練習ができる「復習モード」を用意する。
- 機能以外の工夫：
  
  #### 1. 実践での成功体験を促すリマインド
  「今日学んだフレーズを使ってみよう」という
  リマインド通知を送ることで、
  実際の接客で使うことを促す。
  
  実際に使ってみることで、
  「アプリで学んだことが役に立った」という
  実感を得られるようにする。
  
  #### 2. 店舗での導入サポート
  個人ユーザーだけでなく、
  飲食店の店舗単位での導入も視野に入れる。
  
  店舗で導入することで、
  スタッフ同士で学習状況を共有したり、
  「このフレーズが役立った」という情報を
  店舗内で共有できるようにする。

  #### 3. 定期的なコンテンツ更新
  季節やイベントに応じた
  新しいフレーズを定期的に追加する。
  
  例えば、クリスマスシーズンには
  「クリスマスディナーの予約」に関するフレーズ、
  夏には「冷たい飲み物のおすすめ」に関するフレーズなど。
  
  定期的に新しいコンテンツが追加されることで、
  「今月はどんなフレーズが追加されたかな？」と
  継続的に使いたくなる仕組みを作る。

### 10-2. 技術選定の比較検討

AI会話API
| 候補 | 採用/不採用 | 理由 |

・ドキュメントが豊富で、実装例が多い |
| OpenAI API（GPT-4o-mini） | 不採用 | ・精度は高いが、無料枠がなく、個人開発ではコストがかかる
・音声機能も OpenAI で統一できるが、有料のみ |

| Hugging Face（オープンソースモデル） | 不採用 | ・完全無料だが、自前でホスティングが必要

・学習コストが高い |
| Vercel | 不採用 | ・フロントエンドのデプロイには向いているが、Django のような Python アプリには不向き |



- 今回チャレンジしたい点
AIとの会話機能の実装
Google Gemini API を使って、自然な会話ができる接客アプリを作りたい
飲食店の接客シーンに特化したプロンプト設計に挑戦したい
音声認識・音声合成の実装
ブラウザで音声を録音し、テキストに変換する機能を実装したい
テキストを音声に変換して、ブラウザで再生する機能を実装したい
音声のやり取りで会話が成立する体験を作りたい
- 不安な点
Google Cloud の設定
Google Cloud Console の設定が初めてで、API の有効化や認証の設定がうまくできるか不安
クレジットカードの登録が必要なので、無料枠を超えて課金されないか心配
音声ファイルの扱い
ブラウザで録音した音声ファイルを Django に送信する実装が初めてで、うまくできるか不安
音声ファイルのフォーマット（WebM、MP3 など）の違いに対応できるか心配
音声認識の精度
Google Speech-to-Text API の精度がどれくらいか分からない
接客シーンで使えるレベルの精度が出るか不安
プロンプト設計
Gemini API に対して、どのようなプロンプトを設定すれば自然な会話ができるか分からない
接客シーンに特化したプロンプトの設計が難しそう
開発期間内に完成できるか

初めて使う技術が多く、キャッチアップに時間がかかりそう
MVP として最低限の機能を絞り込めるか不安

### 10-3.キャッチアップ不足の懸念

キャッチアップ不足の段階では以下の懸念点があります。
1. 完成までのハードルが高い
今回のアプリでは、以下の技術が初めての挑戦となります。

| 技術 | 懸念点 |
| --- | --- |
| Google Gemini API | API の使い方やプロンプト設計が初めて |
| Google Speech-to-Text API | 音声認識の精度や音声ファイルのフォーマットに対応できるか不安 |
| Google Text-to-Speech API | 音声合成の音質や自然な音声が生成できるか不安 |
| MediaRecorder API | ブラウザで音声を録音し、Django に送信する実装が初めて |
| Google Cloud Console | API の有効化や認証の設定がうまくできるか不安。無料枠を超えて課金されないか心配 |

これらの技術のキャッチアップには一定の時間を要することが予想されます。

2. Issue の見積もりが難しい
「どこまで理解していて、何が分からないのか」「調査にかかる時間」などが不明瞭な場合、開発期間内に完了することが難しくなってしまいます。

そのため、以下の対応を検討しています。

| 対応 | 内容 |
| --- | --- |
| MVP の機能を絞り込む | まずはテキストベースの会話機能を実装し、音声機能は後から追加する |
| 段階的な実装 | Google Gemini API → Speech-to-Text → Text-to-Speech の順で実装 |
| 技術検証を先に行う | 本格的な実装に入る前に、各 API の動作確認を行う |

3. React や Next.js について
最近注目されている React や Next.js については、 本リリース後に組み込む方向で検討 します。

理由:
React や Next.js は学習コストが高く、MVP 完成までに時間がかかる可能性がある
まずは Django Templates で MVP を完成させ、動くものを作ることを優先する
MVP が完成してから、React や Next.js の導入を検討する方が、開発期間内に完成しやすい
